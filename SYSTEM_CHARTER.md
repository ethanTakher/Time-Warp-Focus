1. Core Function
What the tool does is it helps the user focus on their task: when it is turned on, the chooses a tab they want to focus on, and every letter on every other tab will be translated into hieroglyphics (𓃥), greek (δ), or viking runes (ᚥ).
2. Human Context
The tool enters a browser with different tabs, and focuses on translating what is written into a language that most users won’t understand, to help them focus on their task.
3. Intended User
The intended user is the type of person that is easily distracted and likes history.
4. Behavioral Thesis
The tool changes the language it translates to when the user selects “translation language” before enabling the translation itself (it is a dropdown menu).
5. Dignity Clause
This tool does not manipulate people because the words on other tabs can be translated to English, and the translation can be turned off at any time. It also does not share information about what the users are doing to online buyers.
6. Refusal Clause
This tool will not become something distracting: this will happen because a timer is enabled and, if a user spends 2 times as much time on translated tabs than untranslated ones, the words on the translated tabs are highlighted with the same color as the text to help them get back to work.
7. Atmospheric Tone
It should feel like a normal tab on focus ones, but when the user goes to the other tabs it should feel like they went back into history and have to go back to the future, where they can understand things and where they have tasks/responsibilities.
